1 Introduction

Question: Can speleothem records from DoD2k v2.0 (Evans et al., 2026) be used to reconstruct climate — and is there an ENSO signal in regions where literature expects one (Tadros et al., 2016)?

Data: speleothem time series (δ18O, δ13C, growth rate, Mg/Ca) from DoD2k v2.0 / SISALv3 (Kaushal et al., 2024); instrumental CRU TS v4.07 (Harris et al., 2020) at the nearest grid box; Niño3.4 SST anomalies (NOAA PSL) for ENSO.

Why this matters: Rain and temperature at the surface do not reach a stalagmite unchanged — water mixes in the karst aquifer (Fairchild et al., 2006). We therefore test proxies site by site and region by region, not as one global average.

1.1 Three analysis steps

Step What we do Why
1 — Screen Correlate each series with local CRU temperature and precipitation (1901–2000) See whether any proxy tracks instruments at all
2 — Composite Detrend, calibrate 1901–1980, validate 1981–2000; regional mean of screened series Test whether a group of caves in one region carries a reconstructable signal
3 — ENSO Focus on Australasia / SW Pacific; compare proxies to Niño3.4 and local rainfall Literature links SE Australian hydroclimate to ENSO (Tadros et al., 2016)

Instrumental window: 1901–2000 CE. Calibration: 1901–1980; validation: 1981–2000.

1.2 Proxies at a glance

Proxy Often reflects Caveat
δ18O Rainfall amount, moisture source (region-dependent) Strongly filtered by karst mixing
Mg/Ca Cave temperature or moisture deficit (PCP) In SE Australia linked to palaeorainfall under ENSO (Tadros et al., 2016)
δ13C, growth rate Soil activity, wet vs. dry phases Indirect climate indicators

#' Parse one line from a DoD2k compact array CSV (`id,val1,val2,…`).
#'
#' @param line One CSV line (without header).
#' @return List with `id` and numeric `values`.
parse_array_line <- function(line) {
  parts <- strsplit(line, ",", fixed = TRUE)[[1]]
  list(id = parts[[1]], values = as.numeric(parts[-1]))
}

#' Read a compact array column into a tibble.
#'
#' @param path Path to e.g. `dod2k_v2.0_compact_year.csv`.
#' @return Tibble: `dataset_id`, `values` (list of numeric vectors).
read_array_column <- function(path) {
  lines <- readLines(path, warn = FALSE)
  parsed <- lapply(lines[-1], parse_array_line)
  tibble(
    dataset_id = vapply(parsed, `[[`, character(1), "id"),
    values = lapply(parsed, `[[`, "values")
  )
}

#' Load DoD2k v2.0 compact bundle — one row per dataset, list-columns for time series.
#'
#' @return Wide tibble with metadata, `year`, and `paleoData_values`.
load_dod2k_compact <- function() {
  prefix <- basename(data_dir)
  meta <- read_csv(
    file.path(data_dir, paste0(prefix, "_compact_metadata.csv")),
    show_col_types = FALSE
  ) |>
    rename(dataset_id = any_of(c("datasetId", "...1")))

  years <- read_array_column(file.path(data_dir, paste0(prefix, "_compact_year.csv"))) |>
    rename(year = values)
  values <- read_array_column(
    file.path(data_dir, paste0(prefix, "_compact_paleoData_values.csv"))
  ) |>
    rename(paleoData_values = values)

  meta |>
    left_join(years, by = "dataset_id") |>
    left_join(values, by = "dataset_id")
}

2.4 Long-format catalog

Expands list-columns to one row per (dataset, year) and caches the result as RDS.

Code 
#' Convert compact data to a long catalog (0–2000 CE, finite values only).
#'
#' @param compact Output of [load_dod2k_compact()].
#' @return Tibble: `dataset_id`, `year`, `value`, `lon`, `lat`, `archive_type`, `proxy_type`.
compact_to_catalog <- function(compact) {
  rows <- vector("list", nrow(compact))
  n <- 0L
  for (i in seq_len(nrow(compact))) {
    rec <- compact[i, ]
    yrs  <- rec$year[[1]]
    vals <- rec$paleoData_values[[1]]
    if (!length(yrs) || !length(vals)) next

    ok <- yrs >= year_min & yrs <= year_max & is.finite(vals)
    if (!any(ok)) next

    n <- n + 1L
    rows[[n]] <- tibble(
      dataset_id = rec$dataset_id,
      year = as.integer(yrs[ok]),
      value = as.double(vals[ok]),
      lon = rec$geo_meanLon,
      lat = rec$geo_meanLat,
      archive_type = rec$archiveType,
      proxy_type = rec$paleoData_proxy
    )
  }
  if (!n) return(tibble())
  bind_rows(rows)
}

#' Read cached catalog from `output/cache/dod2k_timeseries.rds`.
#'
#' @return Tibble or `NULL` if cache does not exist.
read_catalog_cache <- function() {
  if (!file.exists(cache_rds)) return(NULL)
  readRDS(cache_rds) |>
    mutate(
      dataset_id = as.character(dataset_id),
      archive_type = as.character(archive_type),
      proxy_type = as.character(proxy_type),
      year = as.integer(year),
      value = as.double(value),
      lon = as.double(lon),
      lat = as.double(lat)
    )
}

#' Load or build the long-format catalog.
#'
#' @param refresh If `TRUE`, rebuild cache from CSV.
#' @return Long-format catalog tibble.
load_dod2k_catalog <- function(refresh = FALSE) {
  if (!refresh) {
    cached <- read_catalog_cache()
    if (!is.null(cached)) return(cached)
  }
  message("Building catalog from compact CSV …")
  catalog <- compact_to_catalog(load_dod2k_compact())
  saveRDS(catalog, cache_rds)
  catalog
}

3.2 Site tables

n_metadata = rows in the archive; n_with_data = series with values in 0–2000 CE.

Code 
#' One row per speleothem series with site metadata.
#'
#' @param catalog Long catalog from [load_dod2k_catalog()].
#' @param compact Wide compact table (for site names).
#' @return Tibble with `dataset_id`, coords, year range, `n_years`, `site`.
speleothem_sites <- function(catalog, compact) {
  sites <- catalog |>
    filter(archive_type == "Speleothem") |>
    group_by(dataset_id, proxy_type, lon, lat) |>
    summarize(
      year_start = min(year),
      year_end = max(year),
      n_years = n(),
      .groups = "drop"
    )

  meta <- compact |>
    filter(archiveType == "Speleothem") |>
    dplyr::select(dataset_id, geo_siteName) |>
    rename(site = geo_siteName)

  sites |>
    left_join(meta, by = "dataset_id") |>
    mutate(
      site = if_else(is.na(site) | site == "" | site == dataset_id, dataset_id, site),
      proxy_type = factor(proxy_type, levels = proxy_order)
    )
}

#' Count metadata rows vs. series with usable time series, by proxy type.
#'
#' @param compact Wide compact table.
#' @param catalog Long catalog.
#' @return Tibble: `proxy_label`, `proxy_type`, `n_metadata`, `n_with_data`.
speleothem_summary <- function(compact, catalog) {
  meta <- compact |>
    filter(archiveType == "Speleothem") |>
    count(paleoData_proxy, name = "n_metadata") |>
    rename(proxy_type = paleoData_proxy)

  with_data <- catalog |>
    filter(archive_type == "Speleothem") |>
    distinct(dataset_id, proxy_type) |>
    count(proxy_type, name = "n_with_data")

  meta |>
    full_join(with_data, by = "proxy_type") |>
    mutate(
      n_metadata = replace_na(n_metadata, 0L),
      n_with_data = replace_na(n_with_data, 0L),
      proxy_label = proxy_labels[proxy_type],
      proxy_type = factor(proxy_type, levels = proxy_order)
    ) |>
    arrange(proxy_type) |>
    transmute(proxy_label, proxy_type, n_metadata, n_with_data)
}

4 Screen against instrumental climate

Each speleothem series is compared to the nearest CRU grid box (0.5°): annual mean temperature, JJA temperature, and annual precipitation (Harris et al., 2020). We use Pearson correlation on detrended annual values (1901–2000). A series needs at least 10 overlapping years.

4.1 CRU grid extraction

#' Download and decompress one CRU TS variable if needed.
#'
#' @param var `"tmp"` or `"pre"`.
#' @return Path to the uncompressed NetCDF file.
ensure_cru_nc <- function(var) {
  fname <- paste0("cru_ts4.07.1901.2022.", var, ".dat.nc")
  nc_path <- file.path(cru_dir, fname)
  gz_path <- paste0(nc_path, ".gz")
  if (!file.exists(nc_path)) {
    if (!file.exists(gz_path)) {
      message("Downloading CRU TS ", var, " …")
      url <- paste(cru_base, var, paste0(fname, ".gz"), sep = "/")
      if (nzchar(Sys.which("curl"))) {
        status <- system2("curl", c("-L", "-C", "-", "--retry", "3", "--max-time", "900", "-o", gz_path, url))
        if (status != 0) stop("CRU download failed for ", var)
      } else {
        utils::download.file(url, gz_path, mode = "wb", timeout = 900)
      }
    }
    message("Decompressing ", basename(gz_path), " …")
    status <- system2("gunzip", c("-k", "-f", gz_path))
    if (status != 0) stop("gunzip failed — decompress ", gz_path, " manually")
  }
  nc_path
}

#' Aggregate monthly CRU matrices to annual temperature means and precipitation sums.
cru_monthly_to_annual <- function(mat_tmp, mat_pre, years = cru_years) {
  n_pt <- nrow(mat_tmp)
  n_yr <- length(years)
  tmp_ann <- tmp_jja <- pre_ann <- matrix(NA_real_, n_pt, n_yr)
  for (j in seq_len(n_yr)) {
    m <- (j - 1L) * 12L + 1:12
    tmp_ann[, j] <- rowMeans(mat_tmp[, m, drop = FALSE], na.rm = TRUE)
    tmp_jja[, j] <- rowMeans(mat_tmp[, m[6:8], drop = FALSE], na.rm = TRUE)
    pre_ann[, j] <- rowSums(mat_pre[, m, drop = FALSE], na.rm = TRUE)
  }
  list(tmp_ann = tmp_ann, tmp_jja = tmp_jja, pre_ann = pre_ann)
}

#' Extract CRU TS climate at speleothem locations (cached as RDS).
#'
#' @param loc Tibble with `loc_id`, `lon`, `lat`.
#' @param refresh Rebuild even when RDS exists.
#' @return Long tibble: `loc_id`, `lon`, `lat`, `year`, `tmp_ann`, `tmp_jja`, `pre_ann`.
load_cru_site_climate <- function(loc, refresh = FALSE) {
  if (!refresh && file.exists(cru_rds)) return(readRDS(cru_rds))

  pts <- vect(loc, geom = c("lon", "lat"), crs = "EPSG:4326")
  tmp_nc <- ensure_cru_nc("tmp")
  pre_nc <- ensure_cru_nc("pre")

  mat_tmp <- as.matrix(
    terra::extract(rast(tmp_nc, subds = "tmp"), pts, method = "simple")[, -1]
  )
  mat_pre <- as.matrix(
    terra::extract(rast(pre_nc, subds = "pre"), pts, method = "simple")[, -1]
  )
  ann <- cru_monthly_to_annual(mat_tmp, mat_pre)

  clim <- map_dfr(seq_len(nrow(loc)), \(i) {
    tibble(
      loc_id = loc$loc_id[i], lon = loc$lon[i], lat = loc$lat[i],
      year = cru_years,
      tmp_ann = ann$tmp_ann[i, ], tmp_jja = ann$tmp_jja[i, ], pre_ann = ann$pre_ann[i, ]
    )
  })
  saveRDS(clim, cru_rds)
  clim
}

#' Correlate one proxy series with one climate variable.
corr_series <- function(proxy_df, clim_df, clim_col,
                        y0 = instr_y0, y1 = instr_y1, min_n = min_overlap) {
  d <- proxy_df |>
    filter(year >= y0, year <= y1) |>
    inner_join(clim_df, by = "year")
  ok <- is.finite(d$value) & is.finite(d[[clim_col]])
  d <- d[ok, , drop = FALSE]
  if (nrow(d) < min_n) {
    return(tibble(r = NA_real_, p = NA_real_, n = nrow(d)))
  }
  ct <- cor.test(d$value, d[[clim_col]], method = "pearson")
  tibble(r = unname(ct$estimate), p = ct$p.value, n = nrow(d))
}

#' Build annual speleothem series (mean if multiple values per year).
speleothem_annual <- function(catalog) {
  catalog |>
    filter(archive_type == "Speleothem") |>
    group_by(dataset_id, proxy_type, lon, lat, year) |>
    summarize(value = mean(value), .groups = "drop")
}

#' Correlate all speleothem series with local CRU grid-box climate.
compute_speleo_correlations <- function(catalog, clim, sites,
                                        y0 = instr_y0, y1 = instr_y1) {
  loc <- sites |> distinct(lon, lat) |> mutate(loc_id = row_number())
  proxy_ann <- speleothem_annual(catalog) |> inner_join(loc, by = c("lon", "lat"))

  res <- map_dfr(group_split(proxy_ann, dataset_id), function(df) {
    cdf <- clim |> filter(loc_id == df$loc_id[1])
    t1 <- corr_series(df, cdf, "tmp_ann", y0, y1)
    t2 <- corr_series(df, cdf, "tmp_jja", y0, y1)
    t3 <- corr_series(df, cdf, "pre_ann", y0, y1)
    tibble(
      dataset_id = df$dataset_id[1],
      proxy_type = df$proxy_type[1],
      lon = df$lon[1], lat = df$lat[1],
      n_overlap = t1$n,
      r_tmp_ann = t1$r, p_tmp_ann = t1$p,
      r_tmp_jja = t2$r, p_tmp_jja = t2$p,
      r_pre_ann = t3$r, p_pre_ann = t3$p
    )
  })

  res |>
    rowwise() |>
    mutate(
      best_var = {
        rs <- c(tmp_ann = r_tmp_ann, tmp_jja = r_tmp_jja, pre_ann = r_pre_ann)
        if (all(is.na(rs))) NA_character_ else names(rs)[which.max(abs(rs))]
      },
      best_r = {
        rs <- c(r_tmp_ann, r_tmp_jja, r_pre_ann)
        if (all(is.na(rs))) NA_real_ else rs[which.max(abs(rs))]
      }
    ) |>
    ungroup()
}

#' Assign coarse continent/region from coordinates (speleothem-focused bins).
assign_region <- function(lon, lat) {
  case_when(
    lat < -10 & lon > 100 ~ "Australasia",
    lat <= 15 & lon >= -85 & lon < -30 ~ "South America",
    lat > 15 & lon < -30 ~ "Americas (north)",
    lat >= 35 & lon >= -15 & lon < 45 ~ "Europe",
    lat >= -35 & lat < 40 & lon >= -20 & lon < 55 ~ "Africa / Med",
    lon >= 50 ~ "Asia",
    TRUE ~ "Other"
  )
}

#' Remove linear trend (preserve mean).
detrend_linear <- function(years, values) {
  ok <- is.finite(values)
  if (sum(ok) < 5L) return(rep(NA_real_, length(values)))
  fit <- lm(values[ok] ~ years[ok])
  resid <- values - predict(fit, newdata = data.frame(years = years))
  resid + mean(values[ok])
}

#' Z-score using reference years only.
zscore_ref <- function(x, years, ref_y0, ref_y1) {
  ref <- x[years >= ref_y0 & years <= ref_y1 & is.finite(x)]
  if (length(ref) < 5L) return(rep(NA_real_, length(x)))
  s <- sd(ref)
  if (!is.finite(s) || s < 1e-8) return(rep(0, length(x)))
  (x - mean(ref)) / s
}

#' Screen series: significant p for assigned best climate variable.
screen_correlations <- function(corr, p_cut = screen_p) {
  corr |>
    mutate(
      region = assign_region(lon, lat),
      p_best = case_when(
        best_var == "tmp_ann" ~ p_tmp_ann,
        best_var == "tmp_jja" ~ p_tmp_jja,
        best_var == "pre_ann" ~ p_pre_ann,
        TRUE ~ NA_real_
      ),
      screened = is.finite(best_r) & !is.na(p_best) & p_best < p_cut & n_overlap >= min_overlap
    )
}

#' Calibrate one site; return annual recon + target in z-space.
calibrate_one_site <- function(proxy_df, clim_df, climate_var,
                               cal_y0, cal_y1, val_y0, val_y1) {
  col <- as.character(climate_col[[as.character(climate_var)]])
  d <- proxy_df |>
    inner_join(
      clim_df |> dplyr::transmute(year, climate = .data[[col]]),
      by = "year"
    ) |>
    filter(year >= cal_y0, year <= val_y1)

  if (nrow(d) < min_overlap) return(NULL)

  d <- d |>
    mutate(
      proxy_dt = detrend_linear(year, value),
      proxy_z = zscore_ref(proxy_dt, year, cal_y0, cal_y1),
      climate_z = zscore_ref(climate, year, cal_y0, cal_y1)
    )

  cal <- d |> filter(year >= cal_y0, year <= cal_y1)
  ok <- complete.cases(cal[, c("proxy_z", "climate_z")])
  if (sum(ok) < min_overlap) return(NULL)

  fit <- lm(climate_z ~ proxy_z, data = cal[ok, ])
  d <- d |>
    mutate(recon_z = predict(fit, newdata = d))

  list(
    data = d |> dplyr::select(year, proxy_z, climate_z, recon_z),
    coef = coef(fit)
  )
}

#' Safe Pearson r (returns NA if fewer than 3 pairs).
safe_cor <- function(x, y) {
  ok <- is.finite(x) & is.finite(y)
  if (sum(ok) < 3L) return(NA_real_)
  cor(x[ok], y[ok])
}

#' Build regional composites for each (region, climate_var) with enough screened series.
build_regional_reconstructions <- function(corr, catalog, clim, sites) {
  loc <- sites |> distinct(lon, lat) |> mutate(loc_id = row_number())
  proxy_ann <- speleothem_annual(catalog) |> inner_join(loc, by = c("lon", "lat"))
  screened <- corr |> filter(screened)

  combos <- screened |>
    count(region, best_var, name = "n") |>
    filter(n >= min_screen_n, !is.na(best_var))

  if (!nrow(combos)) return(tibble())

  bind_rows(compact(map(seq_len(nrow(combos)), function(i) {
    reg <- combos$region[i]
    cv  <- combos$best_var[i]
    sub <- screened |> filter(region == reg, best_var == cv)

    site_recons <- compact(map(sub$dataset_id, function(id) {
      row <- sub |> filter(dataset_id == id)
      px <- proxy_ann |> filter(dataset_id == id)
      cdf <- clim |> filter(loc_id == px$loc_id[1])
      out <- calibrate_one_site(px, cdf, cv, cal_y0, cal_y1, val_y0, val_y1)
      if (is.null(out)) return(NULL)
      out$data |> mutate(
        dataset_id = id,
        sign_r = sign(row[[r_col[[cv]]]][1])
      )
    }))
    if (!length(site_recons)) return(NULL)

    all_years <- bind_rows(site_recons) |>
      mutate(recon_z_signed = if_else(sign_r < 0, -recon_z, recon_z))

    # Regional CRU target: mean across sites, then one z-score (not mean of site z-scores).
    col <- as.character(climate_col[[as.character(cv)]])
    regional_clim <- map_dfr(sub$dataset_id, function(id) {
      px <- proxy_ann |> filter(dataset_id == id) |> slice(1)
      clim |>
        filter(loc_id == px$loc_id) |>
        dplyr::transmute(year, climate = .data[[col]])
    }) |>
      group_by(year) |>
      summarize(climate = mean(climate, na.rm = TRUE), .groups = "drop") |>
      mutate(climate_z = zscore_ref(climate, year, cal_y0, cal_y1))

    composite <- all_years |>
      group_by(year) |>
      summarize(recon_z = mean(recon_z_signed, na.rm = TRUE), .groups = "drop") |>
      left_join(regional_clim |> dplyr::select(year, climate_z), by = "year")

    cal_idx <- composite$year >= cal_y0 & composite$year <= cal_y1
    val_idx <- composite$year >= val_y0 & composite$year <= val_y1

    tibble(
      region = reg,
      climate_var = cv,
      climate_label = recode(cv,
        tmp_ann = "Temperature (annual)",
        tmp_jja = "Temperature (JJA)",
        pre_ann = "Precipitation (annual)"
      ),
      n_series = nrow(sub),
      r_cal = safe_cor(composite$climate_z[cal_idx], composite$recon_z[cal_idx]),
      r_val = safe_cor(composite$climate_z[val_idx], composite$recon_z[val_idx]),
      rmse_cal = sqrt(mean((composite$climate_z[cal_idx] - composite$recon_z[cal_idx])^2, na.rm = TRUE)),
      rmse_val = sqrt(mean((composite$climate_z[val_idx] - composite$recon_z[val_idx])^2, na.rm = TRUE)),
      composite = list(composite),
      site_ids = list(sub$dataset_id)
    )
  })))
}

#' Annual and DJF (Dec–Feb) Niño3.4 for climate year starting in Dec of prior year.
build_nino34_annual <- function(monthly) {
  djf <- monthly |>
    filter(month_num %in% c(12L, 1L, 2L)) |>
    mutate(
      climate_year = if_else(month_num == 12L, year + 1L, year)
    ) |>
    group_by(climate_year) |>
    summarize(nino34_djf = mean(nino34, na.rm = TRUE), .groups = "drop") |>
    rename(year = climate_year)

  ann <- monthly |>
    group_by(year) |>
    summarize(nino34_ann = mean(nino34, na.rm = TRUE), .groups = "drop")

  full_join(ann, djf, by = "year")
}

#' ENSO teleconnection regions [@tadros2016 and SW Pacific literature].
assign_enso_region <- function(lon, lat) {
  case_when(
    lon >= 138 & lon <= 155 & lat >= -40 & lat <= -28 ~ "SE Australia (Tadros)",
    lon >= 130 & lon <= 180 & lat >= -45 & lat <= -10 ~ "Eastern Australasia",
    lon >= 110 & lon <= 180 & lat >= -30 & lat <= 5 ~ "SW Pacific / IASM",
    TRUE ~ NA_character_
  )
}

#' Correlate detrended speleothem annual series with Niño3.4 and local rainfall.
compute_enso_correlations <- function(catalog, clim, sites, nino_ann,
                                      y0 = enso_y0, y1 = enso_y1,
                                      proxies = enso_proxy_order) {
  loc <- sites |> distinct(lon, lat) |> mutate(loc_id = row_number())
  proxy_ann <- speleothem_annual(catalog) |>
    inner_join(loc, by = c("lon", "lat")) |>
    filter(proxy_type %in% proxies)

  map_dfr(group_split(proxy_ann, dataset_id), function(df) {
    reg <- assign_enso_region(df$lon[1], df$lat[1])
    if (is.na(reg)) return(NULL)

    cdf <- clim |> filter(loc_id == df$loc_id[1])
    d <- df |>
      filter(year >= y0, year <= y1) |>
      inner_join(cdf |> dplyr::select(year, pre_ann), by = "year") |>
      inner_join(nino_ann |> dplyr::select(year, nino34_djf, nino34_ann), by = "year")

    d <- d |>
      mutate(value_dt = detrend_linear(year, value))

    ok <- complete.cases(d$value_dt, d$nino34_djf, d$pre_ann)
    d <- d[ok, , drop = FALSE]
    if (nrow(d) < enso_min_overlap) return(NULL)

    ct_djf <- cor.test(d$value_dt, d$nino34_djf, method = "pearson")
    ct_ann <- cor.test(d$value_dt, d$nino34_ann, method = "pearson")
    ct_pre <- cor.test(d$value_dt, d$pre_ann, method = "pearson")

    tibble(
      dataset_id = df$dataset_id[1],
      proxy_type = df$proxy_type[1],
      lon = df$lon[1], lat = df$lat[1],
      enso_region = reg,
      n_overlap = nrow(d),
      r_nino_djf = unname(ct_djf$estimate),
      p_nino_djf = ct_djf$p.value,
      r_nino_ann = unname(ct_ann$estimate),
      p_nino_ann = ct_ann$p.value,
      r_pre_ann = unname(ct_pre$estimate),
      p_pre_ann = ct_pre$p.value
    )
  })
}

lag_join_nino <- function(df, nino_df, col, lag = 0L) {
  nj <- nino_df |>
    dplyr::select(year, nino_v = all_of(col)) |>
    mutate(year = year + lag)
  inner_join(df, nj, by = "year")
}

enso_corr_test <- function(x, y) {
  ok <- complete.cases(x, y)
  if (sum(ok) < enso_min_overlap) return(list(r = NA_real_, p = NA_real_, n = sum(ok)))
  ct <- cor.test(x[ok], y[ok], method = "pearson")
  list(r = unname(ct$estimate), p = ct$p.value, n = sum(ok))
}

compute_enso_sweep <- function(catalog, clim, sites, nino_ann, clim_season = NULL,
                               lags = -1:1) {
  loc <- sites |> distinct(lon, lat) |> mutate(loc_id = row_number())
  proxy_ann <- speleothem_annual(catalog) |>
    inner_join(loc, by = c("lon", "lat")) |>
    filter(proxy_type %in% enso_proxy_order)

  nino_cols <- c("nino34_djf", "nino34_ann")
  clim_cols <- c("pre_ann", "pre_djf", "pre_jja")

  map_dfr(group_split(proxy_ann, dataset_id), function(df) {
    reg <- assign_enso_region(df$lon[1], df$lat[1])
    if (is.na(reg)) return(NULL)

    cdf <- clim |> filter(loc_id == df$loc_id[1])
    if (!is.null(clim_season)) {
      cdf <- cdf |>
        left_join(clim_season |> dplyr::select(loc_id, year, pre_djf, pre_jja),
                  by = c("loc_id", "year"))
    }

    base <- df |>
      filter(year >= enso_y0, year <= enso_y1) |>
      inner_join(cdf, by = c("loc_id", "year")) |>
      mutate(value_dt = detrend_linear(year, value))

    rows <- list()
    for (lag in lags) {
      for (ncol in nino_cols) {
        d <- lag_join_nino(base, nino_ann, ncol, lag)
        ok <- complete.cases(d$value_dt, d$nino_v)
        if (sum(ok) < enso_min_overlap) next
        ct <- enso_corr_test(d$value_dt[ok], d$nino_v[ok])
        rows[[length(rows) + 1L]] <- tibble(
          dataset_id = df$dataset_id[1], proxy_type = df$proxy_type[1],
          enso_region = reg, n_overlap = sum(ok),
          target = ncol, lag = lag, r = ct$r, p = ct$p
        )
      }
      for (ccol in intersect(clim_cols, names(base))) {
        ok <- complete.cases(base$value_dt, base[[ccol]])
        if (sum(ok) < enso_min_overlap) next
        ct <- enso_corr_test(base$value_dt[ok], base[[ccol]][ok])
        rows[[length(rows) + 1L]] <- tibble(
          dataset_id = df$dataset_id[1], proxy_type = df$proxy_type[1],
          enso_region = reg, n_overlap = sum(ok),
          target = ccol, lag = 0L, r = ct$r, p = ct$p
        )
      }
    }
    if (!length(rows)) return(NULL)
    bind_rows(rows)
  })
}

build_enso_composite <- function(sweep, catalog, clim, sites, nino_ann,
                                 region, proxy_type = "d18O",
                                 method = c("baseline", "tuned"),
                                 min_n = 3L) {
  method <- match.arg(method)
  pool <- sweep |>
    filter(enso_region == region, proxy_type == !!proxy_type)

  if (method == "baseline") {
    pick <- pool |>
      filter(target == "nino34_djf", lag == 0L) |>
      arrange(desc(abs(r))) |>
      slice_head(n = max(min_n, 3L))
    nino_col <- "nino34_djf"
    lag <- 0L
  } else {
    pick <- pool |>
      filter(grepl("^nino", target)) |>
      group_by(dataset_id) |>
      slice_max(abs(r), n = 1, with_ties = FALSE) |>
      ungroup() |>
      arrange(desc(abs(r))) |>
      slice_head(n = max(min_n, 5L))
    if (!nrow(pick)) return(NULL)
    nino_col <- pick$target[1]
    lag <- pick$lag[1]
  }

  if (nrow(pick) < min_n) return(NULL)

  loc <- sites |> distinct(lon, lat) |> mutate(loc_id = row_number())
  proxy_ann <- speleothem_annual(catalog) |> inner_join(loc, by = c("lon", "lat"))

  site_ts <- map(pick$dataset_id, function(id) {
    row <- pick |> filter(dataset_id == id)
    px <- proxy_ann |> filter(dataset_id == id)
    cdf <- clim |> filter(loc_id == px$loc_id[1])
    d <- px |>
      filter(year >= enso_y0, year <= enso_y1) |>
      mutate(proxy_dt = detrend_linear(year, value)) |>
      inner_join(cdf |> dplyr::select(year, pre_ann), by = "year")
    d <- lag_join_nino(d, nino_ann, row$target[1], row$lag[1])
    if (nrow(d) < enso_min_overlap) return(NULL)
    d |>
      mutate(
        proxy_z = zscore_ref(proxy_dt, year, enso_y0, 1980L),
        sign_r = sign(row$r[1]),
        proxy_z_signed = if_else(sign_r < 0, -proxy_z, proxy_z)
      ) |>
      dplyr::select(year, proxy_z_signed, nino_v, pre_ann)
  })
  site_ts <- compact(site_ts)
  if (length(site_ts) < min_n) return(NULL)

  composite <- bind_rows(site_ts, .id = "site_idx") |>
    group_by(year) |>
    summarize(
      proxy_z = mean(proxy_z_signed, na.rm = TRUE),
      nino_v = mean(nino_v, na.rm = TRUE),
      pre_ann = mean(pre_ann, na.rm = TRUE),
      n_series = n(),
      .groups = "drop"
    ) |>
    mutate(
      nino_z = zscore_ref(nino_v, year, enso_y0, 1980L),
      proxy_z = zscore_ref(proxy_z, year, enso_y0, 1980L),
      pre_z = zscore_ref(pre_ann, year, enso_y0, 1980L)
    )

  val_idx <- composite$year >= 1981L & composite$year <= enso_y1
  cal_idx <- composite$year >= enso_y0 & composite$year <= 1980L

  nino_label <- if (nino_col == "nino34_djf") "Niño3.4 DJF" else "Niño3.4 annual"

  list(
    region = region,
    proxy_type = proxy_type,
    method = method,
    nino_col = nino_col,
    nino_lag = lag,
    nino_label = nino_label,
    n_series = length(site_ts),
    site_ids = pick$dataset_id[seq_len(length(site_ts))],
    r_cal = safe_cor(composite$nino_z[cal_idx], composite$proxy_z[cal_idx]),
    r_val = safe_cor(composite$nino_z[val_idx], composite$proxy_z[val_idx]),
    r_pre_val = safe_cor(composite$pre_z[val_idx], composite$proxy_z[val_idx]),
    data = composite
  )
}

6.4 Step 3 takeaways

In ENSO regions we tested 13 series. A simple Niño-DJF screen gives 0 significant results; allowing lags and an annual Niño index raises that to 2.

Best baseline teleconnection: sisal_204.0_139 (r = -0.40 vs Niño DJF). Best after retuning: sisal_204.0_139 (r = -0.40 for nino34_djf, lag 0). Only 1 Mg/Ca series exist in SE Australia.

Best tuned δ18O composite (SE Australia (Tadros), 5 series): validation r = 0.60 vs Niño3.4 annual (lag -1).

DoD2k is useful for hypothesis screening, not for a publishable ENSO reconstruction: few Mg/Ca records, annual resolution, and karst mixing damp the signal (Fairchild et al., 2006). A convincing palaeo-ENSO study would need high-resolution, site-calibrated stalagmites and often multi-proxy networks (Tadros et al., 2016).

# Introduction

**Question:** Can speleothem records from DoD2k v2.0 [@evans2026] be used to reconstruct climate — and is there an ENSO signal in regions where literature expects one [@tadros2016]?

**Data:** speleothem time series (δ18O, δ13C, growth rate, Mg/Ca) from **DoD2k v2.0** / SISALv3 [@kaushal2024]; instrumental **CRU TS v4.07** [@harris2020] at the nearest grid box; **Niño3.4** SST anomalies (NOAA PSL) for ENSO.

**Why this matters:** Rain and temperature at the surface do not reach a stalagmite unchanged — water mixes in the karst aquifer [@fairchild2006]. We therefore test proxies **site by site** and **region by region**, not as one global average.

## Three analysis steps

| Step | What we do | Why |
|------|------------|-----|
| **1 — Screen** | Correlate each series with local CRU temperature and precipitation (1901–2000) | See whether any proxy tracks instruments at all |
| **2 — Composite** | Detrend, calibrate 1901–1980, validate 1981–2000; regional mean of screened series | Test whether a *group* of caves in one region carries a reconstructable signal |
| **3 — ENSO** | Focus on Australasia / SW Pacific; compare proxies to Niño3.4 and local rainfall | Literature links SE Australian hydroclimate to ENSO [@tadros2016] |

Instrumental window: **1901–2000 CE**. Calibration: **1901–1980**; validation: **1981–2000**.

## Proxies at a glance

| Proxy | Often reflects | Caveat |
|-------|----------------|--------|
| **δ18O** | Rainfall amount, moisture source (region-dependent) | Strongly filtered by karst mixing |
| **Mg/Ca** | Cave temperature or moisture deficit (PCP) | In SE Australia linked to palaeorainfall under ENSO [@tadros2016] |
| **δ13C**, **growth rate** | Soil activity, wet vs. dry phases | Indirect climate indicators |

```{r}
#' Parse one line from a DoD2k compact array CSV (`id,val1,val2,…`).
#'
#' @param line One CSV line (without header).
#' @return List with `id` and numeric `values`.
parse_array_line <- function(line) {
  parts <- strsplit(line, ",", fixed = TRUE)[[1]]
  list(id = parts[[1]], values = as.numeric(parts[-1]))
}

#' Read a compact array column into a tibble.
#'
#' @param path Path to e.g. `dod2k_v2.0_compact_year.csv`.
#' @return Tibble: `dataset_id`, `values` (list of numeric vectors).
read_array_column <- function(path) {
  lines <- readLines(path, warn = FALSE)
  parsed <- lapply(lines[-1], parse_array_line)
  tibble(
    dataset_id = vapply(parsed, `[[`, character(1), "id"),
    values = lapply(parsed, `[[`, "values")
  )
}

#' Load DoD2k v2.0 compact bundle — one row per dataset, list-columns for time series.
#'
#' @return Wide tibble with metadata, `year`, and `paleoData_values`.
load_dod2k_compact <- function() {
  prefix <- basename(data_dir)
  meta <- read_csv(
    file.path(data_dir, paste0(prefix, "_compact_metadata.csv")),
    show_col_types = FALSE
  ) |>
    rename(dataset_id = any_of(c("datasetId", "...1")))

  years <- read_array_column(file.path(data_dir, paste0(prefix, "_compact_year.csv"))) |>
    rename(year = values)
  values <- read_array_column(
    file.path(data_dir, paste0(prefix, "_compact_paleoData_values.csv"))
  ) |>
    rename(paleoData_values = values)

  meta |>
    left_join(years, by = "dataset_id") |>
    left_join(values, by = "dataset_id")
}
```

## Long-format catalog

Expands list-columns to one row per `(dataset, year)` and caches the result as RDS.

```{r}
#| label: dod2k-catalog
#| code-fold: true

#' Convert compact data to a long catalog (0–2000 CE, finite values only).
#'
#' @param compact Output of [load_dod2k_compact()].
#' @return Tibble: `dataset_id`, `year`, `value`, `lon`, `lat`, `archive_type`, `proxy_type`.
compact_to_catalog <- function(compact) {
  rows <- vector("list", nrow(compact))
  n <- 0L
  for (i in seq_len(nrow(compact))) {
    rec <- compact[i, ]
    yrs  <- rec$year[[1]]
    vals <- rec$paleoData_values[[1]]
    if (!length(yrs) || !length(vals)) next

    ok <- yrs >= year_min & yrs <= year_max & is.finite(vals)
    if (!any(ok)) next

    n <- n + 1L
    rows[[n]] <- tibble(
      dataset_id = rec$dataset_id,
      year = as.integer(yrs[ok]),
      value = as.double(vals[ok]),
      lon = rec$geo_meanLon,
      lat = rec$geo_meanLat,
      archive_type = rec$archiveType,
      proxy_type = rec$paleoData_proxy
    )
  }
  if (!n) return(tibble())
  bind_rows(rows)
}

#' Read cached catalog from `output/cache/dod2k_timeseries.rds`.
#'
#' @return Tibble or `NULL` if cache does not exist.
read_catalog_cache <- function() {
  if (!file.exists(cache_rds)) return(NULL)
  readRDS(cache_rds) |>
    mutate(
      dataset_id = as.character(dataset_id),
      archive_type = as.character(archive_type),
      proxy_type = as.character(proxy_type),
      year = as.integer(year),
      value = as.double(value),
      lon = as.double(lon),
      lat = as.double(lat)
    )
}

#' Load or build the long-format catalog.
#'
#' @param refresh If `TRUE`, rebuild cache from CSV.
#' @return Long-format catalog tibble.
load_dod2k_catalog <- function(refresh = FALSE) {
  if (!refresh) {
    cached <- read_catalog_cache()
    if (!is.null(cached)) return(cached)
  }
  message("Building catalog from compact CSV …")
  catalog <- compact_to_catalog(load_dod2k_compact())
  saveRDS(catalog, cache_rds)
  catalog
}
```

```{r}
#' Count metadata rows vs. series with usable time series, by proxy type.
#'
#' @param compact Wide compact table.
#' @param catalog Long catalog.
#' @return Tibble: `proxy_label`, `proxy_type`, `n_metadata`, `n_with_data`.
speleothem_summary <- function(compact, catalog) {
  meta <- compact |>
    filter(archiveType == "Speleothem") |>
    count(paleoData_proxy, name = "n_metadata") |>
    rename(proxy_type = paleoData_proxy)

  with_data <- catalog |>
    filter(archive_type == "Speleothem") |>
    distinct(dataset_id, proxy_type) |>
    count(proxy_type, name = "n_with_data")

  meta |>
    full_join(with_data, by = "proxy_type") |>
    mutate(
      n_metadata = replace_na(n_metadata, 0L),
      n_with_data = replace_na(n_with_data, 0L),
      proxy_label = proxy_labels[proxy_type],
      proxy_type = factor(proxy_type, levels = proxy_order)
    ) |>
    arrange(proxy_type) |>
    transmute(proxy_label, proxy_type, n_metadata, n_with_data)
}
```

# Screen against instrumental climate

Each speleothem series is compared to the **nearest CRU grid box** (0.5°): annual mean temperature, JJA temperature, and annual precipitation [@harris2020]. We use **Pearson correlation** on detrended annual values (1901–2000). A series needs at least 10 overlapping years.

## CRU grid extraction

```{r}
#| label: cru-setup
#| code-fold: true

cru_dir  <- file.path(cache_dir, "cru_ts")
cru_base <- "https://crudata.uea.ac.uk/cru/data/hrg/cru_ts_4.07/cruts.2304141047.v4.07"
cru_years <- 1901:2022
cru_rds   <- file.path(cache_dir, "cru_site_climate.rds")
dir.create(cru_dir, recursive = TRUE, showWarnings = FALSE)

#' Download and decompress one CRU TS variable if needed.
#'
#' @param var `"tmp"` or `"pre"`.
#' @return Path to the uncompressed NetCDF file.
ensure_cru_nc <- function(var) {
  fname <- paste0("cru_ts4.07.1901.2022.", var, ".dat.nc")
  nc_path <- file.path(cru_dir, fname)
  gz_path <- paste0(nc_path, ".gz")
  if (!file.exists(nc_path)) {
    if (!file.exists(gz_path)) {
      message("Downloading CRU TS ", var, " …")
      url <- paste(cru_base, var, paste0(fname, ".gz"), sep = "/")
      if (nzchar(Sys.which("curl"))) {
        status <- system2("curl", c("-L", "-C", "-", "--retry", "3", "--max-time", "900", "-o", gz_path, url))
        if (status != 0) stop("CRU download failed for ", var)
      } else {
        utils::download.file(url, gz_path, mode = "wb", timeout = 900)
      }
    }
    message("Decompressing ", basename(gz_path), " …")
    status <- system2("gunzip", c("-k", "-f", gz_path))
    if (status != 0) stop("gunzip failed — decompress ", gz_path, " manually")
  }
  nc_path
}

#' Aggregate monthly CRU matrices to annual temperature means and precipitation sums.
cru_monthly_to_annual <- function(mat_tmp, mat_pre, years = cru_years) {
  n_pt <- nrow(mat_tmp)
  n_yr <- length(years)
  tmp_ann <- tmp_jja <- pre_ann <- matrix(NA_real_, n_pt, n_yr)
  for (j in seq_len(n_yr)) {
    m <- (j - 1L) * 12L + 1:12
    tmp_ann[, j] <- rowMeans(mat_tmp[, m, drop = FALSE], na.rm = TRUE)
    tmp_jja[, j] <- rowMeans(mat_tmp[, m[6:8], drop = FALSE], na.rm = TRUE)
    pre_ann[, j] <- rowSums(mat_pre[, m, drop = FALSE], na.rm = TRUE)
  }
  list(tmp_ann = tmp_ann, tmp_jja = tmp_jja, pre_ann = pre_ann)
}

#' Extract CRU TS climate at speleothem locations (cached as RDS).
#'
#' @param loc Tibble with `loc_id`, `lon`, `lat`.
#' @param refresh Rebuild even when RDS exists.
#' @return Long tibble: `loc_id`, `lon`, `lat`, `year`, `tmp_ann`, `tmp_jja`, `pre_ann`.
load_cru_site_climate <- function(loc, refresh = FALSE) {
  if (!refresh && file.exists(cru_rds)) return(readRDS(cru_rds))

  pts <- vect(loc, geom = c("lon", "lat"), crs = "EPSG:4326")
  tmp_nc <- ensure_cru_nc("tmp")
  pre_nc <- ensure_cru_nc("pre")

  mat_tmp <- as.matrix(
    terra::extract(rast(tmp_nc, subds = "tmp"), pts, method = "simple")[, -1]
  )
  mat_pre <- as.matrix(
    terra::extract(rast(pre_nc, subds = "pre"), pts, method = "simple")[, -1]
  )
  ann <- cru_monthly_to_annual(mat_tmp, mat_pre)

  clim <- map_dfr(seq_len(nrow(loc)), \(i) {
    tibble(
      loc_id = loc$loc_id[i], lon = loc$lon[i], lat = loc$lat[i],
      year = cru_years,
      tmp_ann = ann$tmp_ann[i, ], tmp_jja = ann$tmp_jja[i, ], pre_ann = ann$pre_ann[i, ]
    )
  })
  saveRDS(clim, cru_rds)
  clim
}
```

## Correlation functions

Pearson correlation with two-tailed p-value; series with fewer than 10 overlap years are skipped.

```{r}
#| label: corr-setup
#| code-fold: true
#| cache: true

instr_y0 <- 1901L
instr_y1 <- 2000L
min_overlap <- 10L

climate_vars <- c(
  r_tmp_ann = "Temperature (annual)",
  r_tmp_jja = "Temperature (JJA)",
  r_pre_ann = "Precipitation (annual)"
)

#' Correlate one proxy series with one climate variable.
corr_series <- function(proxy_df, clim_df, clim_col,
                        y0 = instr_y0, y1 = instr_y1, min_n = min_overlap) {
  d <- proxy_df |>
    filter(year >= y0, year <= y1) |>
    inner_join(clim_df, by = "year")
  ok <- is.finite(d$value) & is.finite(d[[clim_col]])
  d <- d[ok, , drop = FALSE]
  if (nrow(d) < min_n) {
    return(tibble(r = NA_real_, p = NA_real_, n = nrow(d)))
  }
  ct <- cor.test(d$value, d[[clim_col]], method = "pearson")
  tibble(r = unname(ct$estimate), p = ct$p.value, n = nrow(d))
}

#' Build annual speleothem series (mean if multiple values per year).
speleothem_annual <- function(catalog) {
  catalog |>
    filter(archive_type == "Speleothem") |>
    group_by(dataset_id, proxy_type, lon, lat, year) |>
    summarize(value = mean(value), .groups = "drop")
}

#' Correlate all speleothem series with local CRU grid-box climate.
compute_speleo_correlations <- function(catalog, clim, sites,
                                        y0 = instr_y0, y1 = instr_y1) {
  loc <- sites |> distinct(lon, lat) |> mutate(loc_id = row_number())
  proxy_ann <- speleothem_annual(catalog) |> inner_join(loc, by = c("lon", "lat"))

  res <- map_dfr(group_split(proxy_ann, dataset_id), function(df) {
    cdf <- clim |> filter(loc_id == df$loc_id[1])
    t1 <- corr_series(df, cdf, "tmp_ann", y0, y1)
    t2 <- corr_series(df, cdf, "tmp_jja", y0, y1)
    t3 <- corr_series(df, cdf, "pre_ann", y0, y1)
    tibble(
      dataset_id = df$dataset_id[1],
      proxy_type = df$proxy_type[1],
      lon = df$lon[1], lat = df$lat[1],
      n_overlap = t1$n,
      r_tmp_ann = t1$r, p_tmp_ann = t1$p,
      r_tmp_jja = t2$r, p_tmp_jja = t2$p,
      r_pre_ann = t3$r, p_pre_ann = t3$p
    )
  })

  res |>
    rowwise() |>
    mutate(
      best_var = {
        rs <- c(tmp_ann = r_tmp_ann, tmp_jja = r_tmp_jja, pre_ann = r_pre_ann)
        if (all(is.na(rs))) NA_character_ else names(rs)[which.max(abs(rs))]
      },
      best_r = {
        rs <- c(r_tmp_ann, r_tmp_jja, r_pre_ann)
        if (all(is.na(rs))) NA_real_ else rs[which.max(abs(rs))]
      }
    ) |>
    ungroup()
}

#' Add display labels to correlation results.
enrich_correlations <- function(corr) {
  corr |>
    mutate(
      proxy_type = factor(proxy_type, levels = proxy_order),
      proxy_label = proxy_labels[as.character(proxy_type)],
      best_var_label = recode(
        best_var,
        tmp_ann = "Temperature (annual)",
        tmp_jja = "Temperature (JJA)",
        pre_ann = "Precipitation (annual)",
        .default = NA_character_
      )
    )
}
```

# Step 2 — Regional composite reconstruction

We group caves into coarse regions, keep only series whose local correlation passes p < 0.05, **detrend** each series, **calibrate** it to CRU on 1901–1980, and check whether a regional average still matches instruments on **1981–2000** (validation — data the model did not see during calibration).

```{r}
val_y1 <- 2000L

screen_p <- 0.05

p_col <- c(tmp_ann = "p_tmp_ann", tmp_jja = "p_tmp_jja", pre_ann = "p_pre_ann")
r_col <- c(tmp_ann = "r_tmp_ann", tmp_jja = "r_tmp_jja", pre_ann = "r_pre_ann")

#' Assign coarse continent/region from coordinates (speleothem-focused bins).
assign_region <- function(lon, lat) {
  case_when(
    lat < -10 & lon > 100 ~ "Australasia",
    lat <= 15 & lon >= -85 & lon < -30 ~ "South America",
    lat > 15 & lon < -30 ~ "Americas (north)",
    lat >= 35 & lon >= -15 & lon < 45 ~ "Europe",
    lat >= -35 & lat < 40 & lon >= -20 & lon < 55 ~ "Africa / Med",
    lon >= 50 ~ "Asia",
    TRUE ~ "Other"
  )
}

#' Remove linear trend (preserve mean).
detrend_linear <- function(years, values) {
  ok <- is.finite(values)
  if (sum(ok) < 5L) return(rep(NA_real_, length(values)))
  fit <- lm(values[ok] ~ years[ok])
  resid <- values - predict(fit, newdata = data.frame(years = years))
  resid + mean(values[ok])
}

#' Z-score using reference years only.
zscore_ref <- function(x, years, ref_y0, ref_y1) {
  ref <- x[years >= ref_y0 & years <= ref_y1 & is.finite(x)]
  if (length(ref) < 5L) return(rep(NA_real_, length(x)))
  s <- sd(ref)
  if (!is.finite(s) || s < 1e-8) return(rep(0, length(x)))
  (x - mean(ref)) / s
}

#' Screen series: significant p for assigned best climate variable.
screen_correlations <- function(corr, p_cut = screen_p) {
  corr |>
    mutate(
      region = assign_region(lon, lat),
      p_best = case_when(
        best_var == "tmp_ann" ~ p_tmp_ann,
        best_var == "tmp_jja" ~ p_tmp_jja,
        best_var == "pre_ann" ~ p_pre_ann,
        TRUE ~ NA_real_
      ),
      screened = is.finite(best_r) & !is.na(p_best) & p_best < p_cut & n_overlap >= min_overlap
    )
}

#' Calibrate one site; return annual recon + target in z-space.
calibrate_one_site <- function(proxy_df, clim_df, climate_var,
                               cal_y0, cal_y1, val_y0, val_y1) {
  col <- as.character(climate_col[[as.character(climate_var)]])
  d <- proxy_df |>
    inner_join(
      clim_df |> dplyr::transmute(year, climate = .data[[col]]),
      by = "year"
    ) |>
    filter(year >= cal_y0, year <= val_y1)

  if (nrow(d) < min_overlap) return(NULL)

  d <- d |>
    mutate(
      proxy_dt = detrend_linear(year, value),
      proxy_z = zscore_ref(proxy_dt, year, cal_y0, cal_y1),
      climate_z = zscore_ref(climate, year, cal_y0, cal_y1)
    )

  cal <- d |> filter(year >= cal_y0, year <= cal_y1)
  ok <- complete.cases(cal[, c("proxy_z", "climate_z")])
  if (sum(ok) < min_overlap) return(NULL)

  fit <- lm(climate_z ~ proxy_z, data = cal[ok, ])
  d <- d |>
    mutate(recon_z = predict(fit, newdata = d))

  list(
    data = d |> dplyr::select(year, proxy_z, climate_z, recon_z),
    coef = coef(fit)
  )
}

#' Safe Pearson r (returns NA if fewer than 3 pairs).
safe_cor <- function(x, y) {
  ok <- is.finite(x) & is.finite(y)
  if (sum(ok) < 3L) return(NA_real_)
  cor(x[ok], y[ok])
}

#' Build regional composites for each (region, climate_var) with enough screened series.
build_regional_reconstructions <- function(corr, catalog, clim, sites) {
  loc <- sites |> distinct(lon, lat) |> mutate(loc_id = row_number())
  proxy_ann <- speleothem_annual(catalog) |> inner_join(loc, by = c("lon", "lat"))
  screened <- corr |> filter(screened)

  combos <- screened |>
    count(region, best_var, name = "n") |>
    filter(n >= min_screen_n, !is.na(best_var))

  if (!nrow(combos)) return(tibble())

  bind_rows(compact(map(seq_len(nrow(combos)), function(i) {
    reg <- combos$region[i]
    cv  <- combos$best_var[i]
    sub <- screened |> filter(region == reg, best_var == cv)

    site_recons <- compact(map(sub$dataset_id, function(id) {
      row <- sub |> filter(dataset_id == id)
      px <- proxy_ann |> filter(dataset_id == id)
      cdf <- clim |> filter(loc_id == px$loc_id[1])
      out <- calibrate_one_site(px, cdf, cv, cal_y0, cal_y1, val_y0, val_y1)
      if (is.null(out)) return(NULL)
      out$data |> mutate(
        dataset_id = id,
        sign_r = sign(row[[r_col[[cv]]]][1])
      )
    }))
    if (!length(site_recons)) return(NULL)

    all_years <- bind_rows(site_recons) |>
      mutate(recon_z_signed = if_else(sign_r < 0, -recon_z, recon_z))

    # Regional CRU target: mean across sites, then one z-score (not mean of site z-scores).
    col <- as.character(climate_col[[as.character(cv)]])
    regional_clim <- map_dfr(sub$dataset_id, function(id) {
      px <- proxy_ann |> filter(dataset_id == id) |> slice(1)
      clim |>
        filter(loc_id == px$loc_id) |>
        dplyr::transmute(year, climate = .data[[col]])
    }) |>
      group_by(year) |>
      summarize(climate = mean(climate, na.rm = TRUE), .groups = "drop") |>
      mutate(climate_z = zscore_ref(climate, year, cal_y0, cal_y1))

    composite <- all_years |>
      group_by(year) |>
      summarize(recon_z = mean(recon_z_signed, na.rm = TRUE), .groups = "drop") |>
      left_join(regional_clim |> dplyr::select(year, climate_z), by = "year")

    cal_idx <- composite$year >= cal_y0 & composite$year <= cal_y1
    val_idx <- composite$year >= val_y0 & composite$year <= val_y1

    tibble(
      region = reg,
      climate_var = cv,
      climate_label = recode(cv,
        tmp_ann = "Temperature (annual)",
        tmp_jja = "Temperature (JJA)",
        pre_ann = "Precipitation (annual)"
      ),
      n_series = nrow(sub),
      r_cal = safe_cor(composite$climate_z[cal_idx], composite$recon_z[cal_idx]),
      r_val = safe_cor(composite$climate_z[val_idx], composite$recon_z[val_idx]),
      rmse_cal = sqrt(mean((composite$climate_z[cal_idx] - composite$recon_z[cal_idx])^2, na.rm = TRUE)),
      rmse_val = sqrt(mean((composite$climate_z[val_idx] - composite$recon_z[val_idx])^2, na.rm = TRUE)),
      composite = list(composite),
      site_ids = list(sub$dataset_id)
    )
  })))
}
```

# Step 3 — ENSO-focused screening

**ENSO** (El Niño–Southern Oscillation) is a shift in tropical Pacific sea-surface temperature. We use the **Niño3.4 index** — warm anomalies in the central Pacific often change rainfall in eastern Australia [@tadros2016].

Our speleothem series are **one value per calendar year**. ENSO peaks in **boreal winter (DJF)**, so we also test a **year-mean Niño index** and **lags of ±1 year**, because rain at the cave can respond with a delay. As a second target we use **local summer rainfall (JJA)** from CRU — often a more direct link than the Pacific index itself.

**Regions:** SE Australia [@tadros2016], eastern Australasia, SW Pacific. **Proxies:** Mg/Ca and δ18O only.

```{r}
#' Parse NOAA PSL Niño3.4 monthly anomalies (HadISST, 1981–2010 base).
load_nino34_monthly <- function(refresh = FALSE) {
  if (!refresh && file.exists(nino34_rds)) return(readRDS(nino34_rds))

  if (!file.exists(nino34_dat)) {
    message("Downloading Niño3.4 index …")
    if (nzchar(Sys.which("curl"))) {
      status <- system2("curl", c("-L", "--retry", "3", "-o", nino34_dat, nino34_url))
      if (status != 0) stop("Niño3.4 download failed")
    } else {
      utils::download.file(nino34_url, nino34_dat, mode = "wb")
    }
  }

  lines <- readLines(nino34_dat, warn = FALSE)
  hl <- grep("^[[:space:]]*[0-9]{4}", lines)
  raw <- do.call(rbind, lapply(lines[hl], \(l) as.numeric(scan(text = l, quiet = TRUE))))
  colnames(raw) <- c("year", month.abb)
  monthly <- as_tibble(raw) |>
    pivot_longer(-year, names_to = "month", values_to = "nino34") |>
    mutate(month_num = match(month, month.abb)) |>
    filter(nino34 > -90)

  saveRDS(monthly, nino34_rds)
  monthly
}

#' Annual and DJF (Dec–Feb) Niño3.4 for climate year starting in Dec of prior year.
build_nino34_annual <- function(monthly) {
  djf <- monthly |>
    filter(month_num %in% c(12L, 1L, 2L)) |>
    mutate(
      climate_year = if_else(month_num == 12L, year + 1L, year)
    ) |>
    group_by(climate_year) |>
    summarize(nino34_djf = mean(nino34, na.rm = TRUE), .groups = "drop") |>
    rename(year = climate_year)

  ann <- monthly |>
    group_by(year) |>
    summarize(nino34_ann = mean(nino34, na.rm = TRUE), .groups = "drop")

  full_join(ann, djf, by = "year")
}

#' ENSO teleconnection regions [@tadros2016 and SW Pacific literature].
assign_enso_region <- function(lon, lat) {
  case_when(
    lon >= 138 & lon <= 155 & lat >= -40 & lat <= -28 ~ "SE Australia (Tadros)",
    lon >= 130 & lon <= 180 & lat >= -45 & lat <= -10 ~ "Eastern Australasia",
    lon >= 110 & lon <= 180 & lat >= -30 & lat <= 5 ~ "SW Pacific / IASM",
    TRUE ~ NA_character_
  )
}

#' Correlate detrended speleothem annual series with Niño3.4 and local rainfall.
compute_enso_correlations <- function(catalog, clim, sites, nino_ann,
                                      y0 = enso_y0, y1 = enso_y1,
                                      proxies = enso_proxy_order) {
  loc <- sites |> distinct(lon, lat) |> mutate(loc_id = row_number())
  proxy_ann <- speleothem_annual(catalog) |>
    inner_join(loc, by = c("lon", "lat")) |>
    filter(proxy_type %in% proxies)

  map_dfr(group_split(proxy_ann, dataset_id), function(df) {
    reg <- assign_enso_region(df$lon[1], df$lat[1])
    if (is.na(reg)) return(NULL)

    cdf <- clim |> filter(loc_id == df$loc_id[1])
    d <- df |>
      filter(year >= y0, year <= y1) |>
      inner_join(cdf |> dplyr::select(year, pre_ann), by = "year") |>
      inner_join(nino_ann |> dplyr::select(year, nino34_djf, nino34_ann), by = "year")

    d <- d |>
      mutate(value_dt = detrend_linear(year, value))

    ok <- complete.cases(d$value_dt, d$nino34_djf, d$pre_ann)
    d <- d[ok, , drop = FALSE]
    if (nrow(d) < enso_min_overlap) return(NULL)

    ct_djf <- cor.test(d$value_dt, d$nino34_djf, method = "pearson")
    ct_ann <- cor.test(d$value_dt, d$nino34_ann, method = "pearson")
    ct_pre <- cor.test(d$value_dt, d$pre_ann, method = "pearson")

    tibble(
      dataset_id = df$dataset_id[1],
      proxy_type = df$proxy_type[1],
      lon = df$lon[1], lat = df$lat[1],
      enso_region = reg,
      n_overlap = nrow(d),
      r_nino_djf = unname(ct_djf$estimate),
      p_nino_djf = ct_djf$p.value,
      r_nino_ann = unname(ct_ann$estimate),
      p_nino_ann = ct_ann$p.value,
      r_pre_ann = unname(ct_pre$estimate),
      p_pre_ann = ct_pre$p.value
    )
  })
}

lag_join_nino <- function(df, nino_df, col, lag = 0L) {
  nj <- nino_df |>
    dplyr::select(year, nino_v = all_of(col)) |>
    mutate(year = year + lag)
  inner_join(df, nj, by = "year")
}

load_enso_seasonal_clim <- function(loc) {
  pre_nc <- file.path(cru_dir, "cru_ts4.07.1901.2022.pre.dat.nc")
  if (!file.exists(pre_nc)) return(NULL)
  pts <- vect(loc, geom = c("lon", "lat"), crs = "EPSG:4326")
  mat <- as.matrix(
    terra::extract(rast(pre_nc, subds = "pre"), pts, method = "simple")[, -1]
  )
  map_dfr(seq_len(nrow(loc)), function(i) {
    m <- mat[i, ]
    tibble(
      loc_id = loc$loc_id[i],
      year = cru_years,
      pre_djf = vapply(cru_years, function(yr) {
        dec <- (yr - 1901L) * 12L + 12L
        if (yr == 1901L) return(NA_real_)
        sum(m[c(dec, (yr - 1901L) * 12L + 1:2)], na.rm = TRUE)
      }, numeric(1)),
      pre_jja = vapply(cru_years, function(yr) {
        sum(m[(yr - 1901L) * 12L + 6:8], na.rm = TRUE)
      }, numeric(1))
    )
  })
}

enso_corr_test <- function(x, y) {
  ok <- complete.cases(x, y)
  if (sum(ok) < enso_min_overlap) return(list(r = NA_real_, p = NA_real_, n = sum(ok)))
  ct <- cor.test(x[ok], y[ok], method = "pearson")
  list(r = unname(ct$estimate), p = ct$p.value, n = sum(ok))
}

compute_enso_sweep <- function(catalog, clim, sites, nino_ann, clim_season = NULL,
                               lags = -1:1) {
  loc <- sites |> distinct(lon, lat) |> mutate(loc_id = row_number())
  proxy_ann <- speleothem_annual(catalog) |>
    inner_join(loc, by = c("lon", "lat")) |>
    filter(proxy_type %in% enso_proxy_order)

  nino_cols <- c("nino34_djf", "nino34_ann")
  clim_cols <- c("pre_ann", "pre_djf", "pre_jja")

  map_dfr(group_split(proxy_ann, dataset_id), function(df) {
    reg <- assign_enso_region(df$lon[1], df$lat[1])
    if (is.na(reg)) return(NULL)

    cdf <- clim |> filter(loc_id == df$loc_id[1])
    if (!is.null(clim_season)) {
      cdf <- cdf |>
        left_join(clim_season |> dplyr::select(loc_id, year, pre_djf, pre_jja),
                  by = c("loc_id", "year"))
    }

    base <- df |>
      filter(year >= enso_y0, year <= enso_y1) |>
      inner_join(cdf, by = c("loc_id", "year")) |>
      mutate(value_dt = detrend_linear(year, value))

    rows <- list()
    for (lag in lags) {
      for (ncol in nino_cols) {
        d <- lag_join_nino(base, nino_ann, ncol, lag)
        ok <- complete.cases(d$value_dt, d$nino_v)
        if (sum(ok) < enso_min_overlap) next
        ct <- enso_corr_test(d$value_dt[ok], d$nino_v[ok])
        rows[[length(rows) + 1L]] <- tibble(
          dataset_id = df$dataset_id[1], proxy_type = df$proxy_type[1],
          enso_region = reg, n_overlap = sum(ok),
          target = ncol, lag = lag, r = ct$r, p = ct$p
        )
      }
      for (ccol in intersect(clim_cols, names(base))) {
        ok <- complete.cases(base$value_dt, base[[ccol]])
        if (sum(ok) < enso_min_overlap) next
        ct <- enso_corr_test(base$value_dt[ok], base[[ccol]][ok])
        rows[[length(rows) + 1L]] <- tibble(
          dataset_id = df$dataset_id[1], proxy_type = df$proxy_type[1],
          enso_region = reg, n_overlap = sum(ok),
          target = ccol, lag = 0L, r = ct$r, p = ct$p
        )
      }
    }
    if (!length(rows)) return(NULL)
    bind_rows(rows)
  })
}

build_enso_composite <- function(sweep, catalog, clim, sites, nino_ann,
                                 region, proxy_type = "d18O",
                                 method = c("baseline", "tuned"),
                                 min_n = 3L) {
  method <- match.arg(method)
  pool <- sweep |>
    filter(enso_region == region, proxy_type == !!proxy_type)

  if (method == "baseline") {
    pick <- pool |>
      filter(target == "nino34_djf", lag == 0L) |>
      arrange(desc(abs(r))) |>
      slice_head(n = max(min_n, 3L))
    nino_col <- "nino34_djf"
    lag <- 0L
  } else {
    pick <- pool |>
      filter(grepl("^nino", target)) |>
      group_by(dataset_id) |>
      slice_max(abs(r), n = 1, with_ties = FALSE) |>
      ungroup() |>
      arrange(desc(abs(r))) |>
      slice_head(n = max(min_n, 5L))
    if (!nrow(pick)) return(NULL)
    nino_col <- pick$target[1]
    lag <- pick$lag[1]
  }

  if (nrow(pick) < min_n) return(NULL)

  loc <- sites |> distinct(lon, lat) |> mutate(loc_id = row_number())
  proxy_ann <- speleothem_annual(catalog) |> inner_join(loc, by = c("lon", "lat"))

  site_ts <- map(pick$dataset_id, function(id) {
    row <- pick |> filter(dataset_id == id)
    px <- proxy_ann |> filter(dataset_id == id)
    cdf <- clim |> filter(loc_id == px$loc_id[1])
    d <- px |>
      filter(year >= enso_y0, year <= enso_y1) |>
      mutate(proxy_dt = detrend_linear(year, value)) |>
      inner_join(cdf |> dplyr::select(year, pre_ann), by = "year")
    d <- lag_join_nino(d, nino_ann, row$target[1], row$lag[1])
    if (nrow(d) < enso_min_overlap) return(NULL)
    d |>
      mutate(
        proxy_z = zscore_ref(proxy_dt, year, enso_y0, 1980L),
        sign_r = sign(row$r[1]),
        proxy_z_signed = if_else(sign_r < 0, -proxy_z, proxy_z)
      ) |>
      dplyr::select(year, proxy_z_signed, nino_v, pre_ann)
  })
  site_ts <- compact(site_ts)
  if (length(site_ts) < min_n) return(NULL)

  composite <- bind_rows(site_ts, .id = "site_idx") |>
    group_by(year) |>
    summarize(
      proxy_z = mean(proxy_z_signed, na.rm = TRUE),
      nino_v = mean(nino_v, na.rm = TRUE),
      pre_ann = mean(pre_ann, na.rm = TRUE),
      n_series = n(),
      .groups = "drop"
    ) |>
    mutate(
      nino_z = zscore_ref(nino_v, year, enso_y0, 1980L),
      proxy_z = zscore_ref(proxy_z, year, enso_y0, 1980L),
      pre_z = zscore_ref(pre_ann, year, enso_y0, 1980L)
    )

  val_idx <- composite$year >= 1981L & composite$year <= enso_y1
  cal_idx <- composite$year >= enso_y0 & composite$year <= 1980L

  nino_label <- if (nino_col == "nino34_djf") "Niño3.4 DJF" else "Niño3.4 annual"

  list(
    region = region,
    proxy_type = proxy_type,
    method = method,
    nino_col = nino_col,
    nino_lag = lag,
    nino_label = nino_label,
    n_series = length(site_ts),
    site_ids = pick$dataset_id[seq_len(length(site_ts))],
    r_cal = safe_cor(composite$nino_z[cal_idx], composite$proxy_z[cal_idx]),
    r_val = safe_cor(composite$nino_z[val_idx], composite$proxy_z[val_idx]),
    r_pre_val = safe_cor(composite$pre_z[val_idx], composite$proxy_z[val_idx]),
    data = composite
  )
}
```

DoD2k is useful for **hypothesis screening**, not for a publishable ENSO reconstruction: few Mg/Ca records, annual resolution, and karst mixing damp the signal [@fairchild2006]. A convincing palaeo-ENSO study would need **high-resolution, site-calibrated stalagmites** and often **multi-proxy networks** [@tadros2016].

# Conclusion

| Step | Main result |
|------|-------------|
| **1 — Screen** | Most speleothems correlate weakly with local CRU climate; the archive is heterogeneous. |
| **2 — Composite** | Some regional composites show moderate validation skill; others fail — site mixing matters. |
| **3 — ENSO** | Retuned Niño indices and lags improve correlations modestly; **local rainfall** is often the cleaner target. |
